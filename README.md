<details>
<summary><b>🔍 More spotlight: how the V2V simulation works</b></summary>
<br>

```
Vehicle A sees a hidden stopped car
        ↓
V2V hazard message
        ↓
Vehicle B validates it
        ↓
Cooperative fusion
        ↓
Prediction
        ↓
Collision risk (TTC · TTB)
        ↓
Path clearance score
        ↓
Decision + warning
        ↓
Intent broadcast
        ↓
Nearby vehicles adjust their own plans
```

In the reference run, vehicle B learns about the hazard **2.4 s before its own camera can see it**.
